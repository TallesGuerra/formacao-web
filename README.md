# Lista de Animes

Desafio 02 da Formação Web da Escola Nova Era. A ideia era montar um ranking com os meus 5 animes favoritos usando lista ordenada, imagem, descrição e link.

Cada anime fica num `li` dentro de um `ol`, com pôster, nota que eu dei, uma descrição curta, os gêneros e um link pro MyAnimeList. Coloquei um CSS simples pra deixar em formato de card.

## Ranking

1. Attack on Titan
2. Demon Slayer
3. One Piece
4. Jujutsu Kaisen
5. Spy x Family

## Como abrir

Só abrir o `index.html` no navegador. As imagens estão na pasta `img`.
